# 📝 Task Manager
[![C++](https://img.shields.io/badge/C%2B%2B-11-blue?logo=c%2B%2B)](https://isocpp.org/)
[![Platform](https://img.shields.io/badge/platform-Windows-blue)]()

> Простое консольное приложение для управления списком задач, написанное на C++ с использованием только стандартной библиотеки.

![Демо](https://img.shields.io/badge/статус-рабочий-brightgreen)

---

## 📖 О проекте

**Task Manager** — это  проект, демонстрирующий базовые возможности C++: работа с файлами, структурами данных, обработка пользовательского ввода и ошибок.

### ✨ Особенности
- 💾 **Сохранение данных** — задачи хранятся в текстовом файле и не теряются при перезапуске
- 🛡️ **Защита от ошибок** — некорректный ввод не ломает программу
- 🔄 **Автоматическая перенумерация** — при удалении задачи номера пересчитываются
-  **Поддержка кириллицы** — можно писать задачи на русском языке
- 📦 **Без внешних библиотек** — только стандартная библиотека C++

---

## 🚀 Возможности

| Команда | Описание |
|---------|----------|
| `add <название>` | ➕ Добавить новую задачу |
| `list` | 📋 Показать все задачи |
| `done <номер>` | ✅ Отметить задачу выполненной |
| `undone <номер>` | ↩️ Вернуть задачу в статус "не выполнена" |
| `delete <номер>` | 🗑️ Удалить задачу |
| `delete_all` | 💥 Удалить **все** задачи (с подтверждением) |
| `clear` | 🧹 Удалить только выполненные задачи (с подтверждением) |
| `help` | ❓ Показать справку |
| `exit` | 🚪 Выйти из программы |

## ⚙️ Установка и запуск

### 🟢 Вариант 1: В Visual Studio (рекомендуется)

1. Скачай или склонируй репозиторий:
   ```bash
   git clone https://github.com/USERNAME/task-manager-cpp.git
   ```
2. Открой файл `ConsoleApplication1.cpp` в Visual Studio:
   - **Файл** → **Открыть** → **Файл...** → выбери `ConsoleApplication1.cpp`
3. Нажми **Ctrl + F5** (Запуск без отладки)
4. Программа запустится в консоли Windows

### 🔵 Вариант 2: Компиляция через командную строку (MinGW/g++)

Если у тебя установлен компилятор g++ (например, через MinGW или MSYS2):

```cmd
:: Открой командную строку (cmd) в папке с проектом
cd путь\к\папке\с\проектом

:: Скомпилируй программу
g++ ConsoleApplication1.cpp -o task_manager.exe -std=c++11

:: Запусти
task_manager.exe
```

### 🟡 Вариант 3: Через Developer Command Prompt (MSVC)

Если установлен Visual Studio, но не хочешь открывать IDE:

```cmd

:: Перейди в папку с проектом
cd путь\к\папке\с\проектом

:: Скомпилируй
cl ConsoleApplication1.cpp /EHsc /Fe:task_manager.exe

:: Запусти
task_manager.exe
```

##  Формат хранения данных

Задачи сохраняются в файл `tasks.txt` в директории с программой.  
Каждая строка файла — одна задача в формате:

```
ID|STATUS|TITLE
```

| Поле | Тип | Описание |
|------|-----|----------|
| `ID` | `int` | Порядковый номер задачи (1, 2, 3...) |
| `STATUS` | `0` или `1` | `0` — не выполнена, `1` — выполнена |
| `TITLE` | `string` | Название задачи |

###  Пример содержимого `tasks.txt`
```
1|0|Купить продукты
2|1|Сделать домашнее задание
3|0|Позвонить другу
```

## 🧩 Архитектура кода

Программа разделена на логические функции:

| Функция | Назначение |
|---------|------------|
| `load_tasks()` | Загрузка задач из файла |
| `save_tasks()` | Сохранение задач в файл |
| `add_task()` | Добавление новой задачи |
| `print_tasks()` | Вывод списка задач на экран |
| `update_task_status()` | Изменение статуса задачи |
| `delete_task()` | Удаление задачи по ID |
| `clear_completed_tasks()` | Удаление всех выполненных задач |
| `delete_all_tasks()` | Удаление всех задач |
| `renumber_tasks()` | Перенумерация задач |
| `print_help()` | Вывод справки |

##  Обработка ошибок

Программа корректно обрабатывает:
- ❌ Отсутствие файла `tasks.txt` при первом запуске
- ❌ Пустой ввод (просто Enter)
- ❌ Ввод букв вместо номера задачи
- ❌ Несуществующий номер задачи
- ❌ Неизвестные команды

## 🎨 Поддержка кириллицы

Программа настроена для корректной работы с русским языком в консоли Windows:
- Используется кодировка **Windows-1251** (CP1251)
- Автоматически переключается кодировка консоли через `chcp 1251`
- Можно писать названия задач на русском языке

##  Возможные проблемы и решения

### Проблема: "Кракозябры" вместо русских букв
**Решение:** Убедись, что файл `ConsoleApplication1.cpp` сохранён в кодировке **Windows-1251**:
1. В Visual Studio: **Файл** → **Дополнительные параметры сохранения**
2. Выбери кодировку **Кириллица (Windows) - 1251**
3. Сохрани и перекомпилируй

### Проблема: Консоль сразу закрывается после запуска
**Решение:** Запускай программу через **Ctrl + F5** (без отладки), а не через F5.

### Проблема: Ошибки компиляции
**Решение:** Убедись, что в проекте установлен стандарт C++11 или новее:
- **Свойства проекта** → **C/C++** → **Язык** → **Стандарт языка C++** → **C++14** или выше
